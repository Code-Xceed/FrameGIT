# 1. PRODUCT VISION

FrameGit is a Git/GitHub-like version-control platform for professional creative applications, starting with video editing.

The initial target editors are:

1. Adobe Premiere Pro
2. DaVinci Resolve

The long-term platform should potentially support:

- After Effects
- Blender
- Photoshop
- Final Cut Pro
- Audition
- other professional creative applications

The core idea:

> Give creative professionals the same fundamental workflow developers have with Git/GitHub: version history, commits, branches, restore, collaboration, project cloning, synchronization, and reliable recovery.

But creative projects are fundamentally different from source code.

A video project may contain:

- hundreds of GB
- multiple TB
- video
- audio
- images
- fonts
- LUTs
- plugins
- project files
- proxies
- generated media
- external dependencies

Therefore FrameGit must NOT simply treat everything as normal Git files.

# 4. IMPORTANT PRODUCT DISTINCTION

Do NOT attempt to make editor Undo/Redo identical to FrameGit version history.

Treat them as two layers unless research proves they can safely be integrated.

Conceptually:

```text
Editor Undo/Redo
=
short-term editing history

FrameGit
=
persistent project history
```

Example:

```text
10:01
Move clip

10:02
Change color

10:03
Undo

10:04
Change audio

                 ↓

FrameGit snapshot/commit
"Audio revision"
```

FrameGit must understand the current project state without corrupting or interfering with the editor's native undo/redo system.

```text

```

1. Authenticate the user
2. Retrieve repository metadata
3. Retrieve the selected commit
4. Retrieve the asset manifest
5. Determine required chunks
6. Download required chunks
7. Reconstruct files
8. Restore project paths/references
9. Restore project state
10. Open the project in the correct editor

Support:

### Full clone

Download everything.

### Smart clone

Download:

- project
- metadata
- proxies
- currently required assets

### Selective clone

Download only:

- selected sequences
- selected assets
- selected folders

### Lazy clone

Download assets only when required.
